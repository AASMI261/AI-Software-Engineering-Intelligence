# DevRecovery Test Repository

A small Java project with intentional issues for testing a code-analysis workflow.

## Files
- `src/main/java/demo/Calculator.java`: division-by-zero edge case and an addition logic bug
- `src/main/java/demo/UserService.java`: null-handling examples
- `src/main/java/demo/FileReaderService.java`: minimal file-path handling example
- `src/test/java/demo/CalculatorTest.java`: illustrative JUnit tests

These examples are intentionally imperfect test fixtures, not production-ready code.
